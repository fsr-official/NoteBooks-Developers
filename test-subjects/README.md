# Renderer test subjects

These pages are practical fixtures to open in the production NoteBooks reader. They are documentation and regression subjects, not a claim that every possible syntax combination is supported.

## Current subjects

- [Markdown and mathematics](markdown-and-math.md)
- [Desmos 2D](desmos-2d.md)
- [Desmos 3D](desmos-3d.md)

When checking a renderer change, verify the expected result, malformed-input diagnostics, narrow and wide layouts, and browser console output. Keep experimental formats separate until their parser and safety model are implemented.
